# Trip Kit

Itinerary, to-do list, Malaysia public holidays, currency converter and outfit log.
Data is saved in the browser (localStorage). No accounts, no backend.

    npm install
    npm run dev

## Deploy to Vercel
Push to GitHub, then import the repo at vercel.com/new. Vercel detects Vite; no settings needed.
(Build: `npm run build`, output: `dist`.)

APIs used (no keys): date.nager.at (holidays), api.frankfurter.dev (exchange rates).
